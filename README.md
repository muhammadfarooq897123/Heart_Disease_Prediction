# Heart Disease Detection

A machine learning project that predicts whether a patient is likely to have heart disease based on health and lifestyle data.

## Dataset

`heart.csv` contains 1,000 patient records with these features:

- **Demographics:** Age, Gender
- **Health measures:** Cholesterol, Blood Pressure, Heart Rate, Blood Sugar
- **Lifestyle:** Smoking, Alcohol Intake, Exercise Hours, Stress Level
- **Medical history:** Family History, Diabetes, Obesity
- **Symptoms:** Exercise Induced Angina, Chest Pain Type
- **Target:** Heart Disease (1 = yes, 0 = no)

## Files

- `Code.ipynb`: the main notebook (data exploration, model training, and evaluation)
- `heart.csv`: the dataset
- `Heart_Disease_Prediction.pdf`: project report

## How to run

1. Clone the repository:
   `git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git`
2. Install the libraries:
   `pip install pandas numpy scikit-learn matplotlib seaborn jupyter`
3. Launch the notebook:
   `jupyter notebook Code.ipynb`
